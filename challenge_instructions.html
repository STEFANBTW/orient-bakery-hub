The "Rising Dough" Build Challenge

Can you rebuild the Orient Bakery Hub from scratch?

The Mission

Take the raw React/TSX fragments and consolidate them into a single, working HTML file that runs in a browser without a build step (Vite/NPM).

The Rules

  • No Vite/NPM: The final result must be a single index.html.
  • The CDNs: You must use the Babel Standalone and Tailwind CDN to handle the JSX and styling.
  • The Glue: You need to create a HashRouter and an entry point to mount the components.
  • Cleanliness: Use proper AI-Readable comments so future me (or an AI) can understand your work.

How to Start

1. Open the index.html of this project.

2. View the "Source Fragments" linked in the hidden menu.

3. Start with the HTML shell and the importmap.
