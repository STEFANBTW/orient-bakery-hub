# 🚀 Pushing Orient Command Center to GitHub Follow these steps to create your repository and push the code. ### 1. Initialize Local Repository Open your terminal in the project root and run: ```bash git init git add . git commit -m "Initial commit: Orient Command Center God Mode" ``` ### 2. Create Repository on GitHub 1. Log in to [GitHub](https://github.com). 2. Click the **+** icon and select **New repository**. 3. Name it `orient-command-center`. 4. Keep it Public or Private as preferred. 5. **Do not** initialize with a README, license, or .gitignore (we already have them). 6. Click **Create repository**. ### 3. Link and Push Copy the remote URL from GitHub and run: ```bash # Replace with the URL from GitHub git remote add origin git branch -M main git push -u origin main ``` ### 4. Continuous Deployment (Optional) Once pushed, you can connect this repo to platforms like **Vercel** or **Firebase App Hosting** for automatic deployments every time you push new changes.
