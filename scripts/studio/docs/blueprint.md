# **App Name**: Orient Command Center

## Core Features:

- Secure Admin Navigation: A persistent sidebar provides organized access to all main dashboard sections: Overview, Orders, Inventory, Users, Analytics, and Settings, with prominent 'ORIENT ADMIN' branding.
- Command Center Overview: Displays critical business metrics (Total Revenue, Active Orders, Online Users, Low Stock Alerts), a real-time activity feed, and a 7-day revenue chart for at-a-glance system health.
- AI-powered System Anomaly Alerts: Utilizes an AI tool to monitor key metrics and the real-time activity feed, flagging unusual activity or critical issues for immediate staff attention.
- Order Fulfillment Management: Provides a detailed table view of all orders, enabling status updates and the ability to print receipts via a modal preview.
- Product Inventory Control: Manages product listings, allowing quick toggling of 'Out of Stock' status and editing of product prices.
- User Relationship Management: Lists all registered users, displays clear status badges (VIP, New, Banned), and offers an immediate 'Ban User' action for managing user access.

## Style Guidelines:

- Primary color: A sophisticated, deep violet-blue (#8A4DE6) to convey luxury and technological authority, standing out against dark backgrounds.
- Background color: A very dark slate with a hint of purple (#1F1C21), maintaining the requested deep black theme.
- Accent color: A brighter, vibrant blue (#859EFF) for interactive elements and highlights, ensuring clear contrast.
- Status indicators: Distinct green (#4DE64D) for 'Good' status and red (#E64D4D) for 'Critical' alerts.
- Headline and body font: 'Inter', a clean sans-serif for optimal readability and a modern, objective feel in a high-density interface.
- Data and code font: 'Source Code Pro', a monospaced sans-serif, ensuring clarity and precise alignment for numerical and technical data.
- Utilize Lucide React for a comprehensive set of clean, outline-style icons, ensuring clear visual representation and high scannability in the dense interface.
- Leverage a consistent dark mode theme with a background similar to 'bg-slate-950' and subtle, minimal borders ('border-white/10'). Optimize layout for desktop and tablet with a responsive, high-density grid system for command center views, prioritizing efficient information display and hierarchy.
- Implement subtle yet precise transitions and micro-interactions using Framer Motion. Focus on smooth navigations, data updates, and state changes to enhance user experience without distracting from high information density, emphasizing speed and efficiency.
