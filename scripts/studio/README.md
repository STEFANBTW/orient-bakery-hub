# Orient Internal Omni Dashboard (God Mode)

## 🏛️ The Manifesto
The Orient Command Center is a high-stakes, role-based governance platform designed for the multi-division luxury lifestyle corporation. It is engineered to transform corporate data into decisive action while maintaining a premium, authoritative aesthetic.

---

## 🔐 Authentication & RBAC
The system uses **Firebase Authentication** and **Firestore** to enforce strict division isolation.

### Role Tiers:
1.  **CEO / General Manager (Boss)**
    *   **Scope:** Global. Accesses the master performance matrix and authorizes staff enrollment.
2.  **Head of Division (HOD)**
    *   **Scope:** Division-Specific. Sanitizes staff proposals and publishes live content.
3.  **Operational Staff**
    *   **Scope:** Task-Specific. Drafts changes and proposes edits for superior review.

### 🛡️ The ActionGuard Protocol
Every sensitive action is wrapped in an **ActionGuard**.
*   **If Authorized:** The action executes immediately.
*   **If Unauthorized:** The intent is automatically converted into a "Proposal" and routed to the HOD's inbox.
